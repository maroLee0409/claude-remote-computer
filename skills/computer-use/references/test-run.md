# 업무 프로그램 시험을 뒤에서 돌리고 녹화하기

유지보수 지시를 받아 고친 뒤 "화면에서 정말 되는지"를 사람 대신 돌려 보고, **영상 하나**로 보여 주는 절차.
사용자는 그동안 자기 일을 한다. 창을 앞으로 가져오지 않고, 마우스·키보드를 안 쓴다.
왜 이렇게 만들었는지는 저장소 `docs/design-background-control.md`.

## 사람이 하는 것 (자동화하지 않는다)

- **Claude 를 관리자로 띄우기** — 대상 앱이 관리자로 떠야 하는 경우만. 한 번 켜 두면 그 세션 동안 유지된다.
  UAC 를 건너뛰는 장치(자동 승인, 예약 작업 우회 등)는 만들지 않는다.
- **로그인** — 비밀번호는 Claude 가 넣지 않는다. 저장해 두지도 않는다. 로그인 창이 뜨면 알리고 기다린다.
  앱에 "아이디 저장"·자동 로그인 기능이 있으면 그건 앱이 하는 일이니 쓴다.
- **창 배치** — 누를 버튼 자리가 다른 창에 덮이지 않게, 대상 앱을 다른 모니터에 둔다(pitfalls 11).

## 순서

```bash
RC="$HOME/.claude/skills/computer-use/scripts/rc.py"
export PYTHONIOENCODING=utf-8
OUT="$HOME/Videos/rc"; mkdir -p "$OUT"      # 영상 둘 곳 - 사용자에게 이 경로를 알려 준다
```

**1. 떠 있나 본다.** `python "$RC" windows` — 메인 창 제목(예: `Browser - [`)이 있으면 3번으로.

**2. 띄우고 로그인을 기다린다.**
```bash
python "$RC" launch "바로가기 이름"            # "관리자 권한 - 못 다룬다" 가 찍히면 멈추고 사용자에게 (pitfalls 12)
python "$RC" waitwin "Browser - [" 600         # 사용자가 로그인할 때까지. 그동안 "로그인해 주세요" 라고 알린다
```

**3. 녹화를 켠다.** 백그라운드로 띄운다(Bash `run_in_background`, 또는 끝에 `&`).
```bash
python "$RC" record "$OUT/$(date +%Y%m%d-%H%M)-시험이름.gif" 1800 --bg "Browser - ["
```

**4. 시험한다 — 전부 `--bg`.** 한 단계마다: 찍기 → 누르기 → 바뀔 때까지 기다리기 → 찍어서 확인.
```bash
python "$RC" shot s.png --bg "Browser - ["                       # 보고 좌표를 읽는다
python "$RC" click X Y --bg "Browser - [" --img s.png            # 메뉴·탭·버튼
python "$RC" dblclick X Y --bg "Browser - [" --img s.png         # 메뉴 트리에서 화면 열기
python "$RC" type "값" --bg "Browser - ["                        # 입력칸을 click --bg 한 뒤
python "$RC" waitstable --bg "Browser - [" 15                    # 조회·로딩 끝날 때까지
python "$RC" ui get "Browser - [" 컨트롤이름                     # 값은 글자로 읽을 수 있으면 글자로
```
- 오류·확인 대화상자는 제목이 따로다(예: `J Dialog`). `windows` 로 보고 `ui get "그 제목" txtMessage` 로 글을 읽는다.
- 누른 게 안 먹으면(화면이 그대로) 덮였는지부터 본다 — `click --bg` 가 `[주의] 덮고 있다` 를 찍는다.
  **앞으로 가져와 누르는 걸로 넘어가지 않는다.** 멈추고 "그 창을 안 덮이는 곳으로 옮겨 달라"고 한다.

**5. 녹화를 멈추고 알린다.**
```bash
python "$RC" record stop                 # 녹화 쪽이 GIF 를 쓰고 끝난다 - 백그라운드 작업이 끝났다는 알림을 기다린다
```
보고: 영상 경로, 단계별 결과(된 것 / 안 된 것과 그때 화면 문구 그대로), 사람이 볼 지점(몇 초쯤 무엇).

## 하지 않는 것

- **저장·삭제·확정·전송 버튼은 지시에 명시된 것만** 누른다. 조회는 된다. 운영 DB 에 붙은 화면이면 저장 전에 묻는다.
- 시험용 값은 지시나 사용자에게서 받은 것만 넣는다. 지어내지 않는다.
- 화면에 보이는 비밀번호·연결 문자열은 보고에 옮기지 않는다.

## 녹화에 대해

- 그 창만 `PrintWindow` 로 찍는다 — 다른 창이 덮어도, 사용자가 다른 일을 해도 그 창만 나온다. **최소화하면 멈춘다.**
- 바뀐 장면만 담는다(초당 2장 확인). 가만있는 동안은 앞 장면이 길게 보인다. 그래서 30분짜리도 크지 않다.
- GIF 는 브라우저·탐색기 미리 보기에서 바로 재생된다. 쉴 새 없이 바뀌는 화면을 오래 찍으면 메모리가 커진다(코드에 `ponytail:`).
